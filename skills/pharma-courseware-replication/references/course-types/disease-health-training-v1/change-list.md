# 换主题更新点 · 疾病健康知识培训课型

## 必须改（content）

- [ ] 封面主题名、系列名
- [ ] 目录章节名（随删减板块调整）
- [ ] 疾病定义与病因
- [ ] 临床表现各块
- [ ] 检查方法要点
- [ ] 一般/全身/局部治疗描述
- [ ] 对症用药表全部行
- [ ] 各药品注意事项（禁用表述须审核）
- [ ] 专业关怀与特殊人群
- [ ] 一页通浓缩文案

## 必须换图（business_asset）

- [ ] 对症表/注意页涉及的授权包装图
- [ ] 品牌/系列 logo（若更换组织识别）

## 建议重生（system_generate）

- [ ] 疾病概览主图
- [ ] 检查/解剖示意
- [ ] 治疗方式示意（休息、雾化、喷鼻等中性图）
- [ ] 关怀类图标（饮水、通风、疫苗等）
- [ ] 无真包装时的药名坑位占位图

## 不要动

- [ ] 「概览→表现→检查→治疗→注意→关怀→总结」信息架构（可删无内容节，勿乱序堆砌）
- [ ] 已锁定的 style token
- [ ] 表头「临床症状 | 对症用药」类框架列名逻辑

## 最少输入包

1. 病名 + 医学审核稿（定义/临床/检查/治疗/注意）  
2. 对症表药品清单 + 授权包装（或明确仅坑位名）  
3. 是否需要一页通  
4. 特殊人群口径是否允许出现
