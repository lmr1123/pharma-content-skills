# 页序地图 · 疾病健康知识培训（参课蓝金样拆解）

共 **18** 页。正文来自金样结构学习，换病须医学审核稿。

| 页 | page_type / scene | 教学目的 | 结构要点 | 换主题关键动作 |
|----|-------------------|----------|----------|----------------|
| 01 | `cover` | 课程身份 | 品牌/系列/主题/讲师信息区 | 主题名、系列、讲师（若有） |
| 02 | `agenda` | 目录 | 编号章节 | 章节名随板块裁剪 |
| 03 | `disease_overview` | 定义+病因 | 定义句 + 病因块 + 示意槽 | 全文+主图 |
| 04 | `symptoms` / clinical | 临床表现 | 分型/场景描述块 | 各临床块正文 |
| 05 | `custom` exam | 检查方法 | 双栏要点 + 病原/示意 | 检查要点列表 |
| 06 | `medication_advice` | 一般治疗 | 插图 + 正文 | 一般治疗条文 |
| 07 | `medication_advice` | 全身用药 | 插图 + 要点强调 | 全身用药原则（审定） |
| 08 | `medication_advice` | 局部用药 | 多图槽 + 正文 | 局部处理描述 |
| 09 | `usage` 对症表 | 对症用药表 | 两列表 + 包装坑位行 | **表行按实际药数**；坑位名 |
| 10–14 | `caution` | 药品注意事项 | 药名 + 注意列表；（禁用标红） | 每药注意；无则删页 |
| 15 | `medication_advice` care | 专业关怀 | 横幅要点 + 三卡 | 关怀条文与图 |
| 16 | `medication_advice` | 特殊人群关怀 | 疫苗/特殊人群卡 | 特殊人群口径（审定） |
| 17 | `outro` | 收尾 | 讲师/口号 | 可换系列收束 |
| 18 | `summary` 一页通 | 手机可读总结 | 概览+表现+用药表+关怀浓缩 | 全文浓缩重写 |

## 槽位角色

| role | 典型 |
|------|------|
| `framework` | 蓝系页眉页脚、章节号、表头样式（跟参考；非门店活力换皮） |
| `content` | 定义、临床、检查、治疗、表单元格、注意事项条文 |
| `business_asset` | 对症表/注意页中的 **授权包装**；系列 logo |
| `system_generate` | 解剖/检查/护理/疫苗等中性插图；无包装时的 **胶囊形坑位占位** |

## 硬规则

- 不要 AI 伪造真实品牌包装  
- 不要编造未审核药品禁忌  
- 红字仅用于含「禁用」的表述  
- 末页一页通可保留为「总结页」版式（本 Skill PPTX 用 16:9 总结卡近似，不必强制竖版画布）
