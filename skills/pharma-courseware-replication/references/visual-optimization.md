# 视觉优化原则（PPT 层）

在 **大框架（页序叙事、板块职责）不变**、且 **不更换业务认可/品牌 PPT 风格** 的前提下，让沉淀后的模板更整齐、更像「同一套」——是 **收敛与提升**，不是 **换皮**。

## 目标

1. 全课件共享 **从参考抽取** 的同一套 token（色、字号、圆角、页眉页脚）
2. 信息层级清晰：标题 > 要点 > 注释
3. 投影可读：对比度足够、对齐一致
4. 换主题后 PPT 视觉不漂：只换内容与主题图，**不换** 母版语言

## 允许的优化（在参考风格内部）

| 类别 | 示例 |
|------|------|
| 对齐与网格 | 统一边距、卡片等宽、基线对齐 |
| 层级 | 主标题/小节号/正文三级固定（字号取自参考量级） |
| 装饰收敛 | 去掉互相冲突的多余花纹，保留参考里的主装饰语言 |
| 对比度 | 正文加深到可读（仍用参考主色体系） |
| 图槽规范 | 统一圆角与描边；缺包装用命名占位框 |
| 页眉页脚 | 样式跟参考统一（组织名 / 内部学习 / 页码） |

## 禁止的「优化」

- **用另一套默认风格（含「门店活力」）覆盖整份 PPT 色板与母版**
- 无确认把绿系课件改成暖橙系、把参课蓝改成别的品牌色
- 擅自删减教学必备板块（业务确认可删除外）
- 把医学结论写得更绝对
- 用生成包装图替换真包装位
- 从参考 **抠图** 当生产素材（只学构图；插图另按插图策略处理）

## 有参考时（常规）

1. 抽样 3～5 页提取：主色、辅色、背景、标题色、卡片底、页眉规则  
2. 记录字体倾向（无授权字体则回落系统无衬线，**色板仍跟参考**）  
3. 写 `visual/style-spec.md`，标注 `source: extracted-from-reference`  
4. 优化 = 在该 token 上对齐与收敛  

## 参考几乎无视觉语言时

1. **先问业务**：品牌色 / 样例页 / 「就按纯文字结构先出」  
2. 未确认前：可用 **中性可编辑壳** 只验证结构，并在 `before-after.md` 标明「版式待品牌确认」  
3. **不要** 默认写成门店活力整页风格  

## 插图另册

缺图、画风不匹配、或业务要求补插图时：见 `style-selection.md` **B 层**，默认插图画风 `store-vitality-v1`。  
插图默认风 **不影响** 本文件的 PPT token。

## before-after 最少写三条

1. 保留了什么（页序/板块 + **参考主色/版式语言**）  
2. 统一了什么（对齐、层级、装饰收敛——仍在原体系内）  
3. 插图：哪些跟参考、哪些用门店活力新生成
