# 插图画风 · 门店活力 store-vitality-v1

| 项 | 值 |
|----|-----|
| style_id | `store-vitality-v1` |
| 中文名 | 门店活力 |
| **适用范围** | **仅** `system_generate` 知识插图 / 坑位示意 / 图标风插画 |
| **不适用** | PPT 整页色板、页眉页脚、卡片母版、品牌 chrome（那些跟业务参考） |

## 何时启用

- 页面需要图，但参考中 **无图 / 图空**  
- 参考插图 **风格不统一或不匹配** 当前模板  
- 业务 **明确要求** 补插图或统一插画风  

**不启用：** 用本规格去「重做整份 PPT 视觉」。

## 画风描述（生图用）

- 气质：门店培训友好、清晰、偏扁平/轻质感插画，信息可读  
- 色彩：暖色点缀（橙/琥珀）+ 干净浅底；可点缀青绿作对比  
- 内容：中性医学/零售场景示意；**不出现** 可辨认真实商品包装与商标  
- 构图：主体居中或卡片内安全区；留白适中，适合嵌进已有 PPT 图槽  
- 禁止：写未审定药效大字报、恐吓风格、低俗表情包感  

## 与 PPT 版式的关系

```text
PPT chrome / 色板  ←  visual/style-spec.md（来自参考）
插图文件           ←  assets/provided/（本规格生成）
嵌入方式           ←  图槽尺寸与圆角跟 PPT style-spec，不跟本文件改主题色
```

## tokens.json

本目录 `tokens.json` 供 **插图配色提示** 与（可选）占位图标着色；  
整页母版只读模板包 `visual/tokens.json`（PPT 层）；本文件仅指导插图生成。
