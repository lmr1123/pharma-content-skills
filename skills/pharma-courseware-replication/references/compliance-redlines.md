# 医药内训 · 合规与素材红线

本 Skill 全流程适用。

## 文案

1. **不编造**适应症、用法用量、禁忌、临床数据、「第一」「最好」等断言。  
2. 功效/卖点：仅写入业务已提供或已标来源的文字；否则 `pending_business` / `pending_review`。  
3. 参考上的数字与结论默认不当作已审定事实；换主题须重确认。  

## 素材

1. 包装、商标、证照：业务授权真图；禁止生成图冒充实拍包装。  
2. 参考插画/摄影：只学构图与层级，不直接抠图当生产资产（版权风险）。  
3. 知识插图可生成到 `assets/provided/`，图上不写未审定药效断言。  

## 交付

1. 模板包 + PPTX **不等于** 医学/法务已通过。  
2. 本 Skill **独立运行**，不要求安装其他内容生产系统。  
3. 业务模板默认仅本机 `workspace/`；公开分享前去掉敏感包装。
