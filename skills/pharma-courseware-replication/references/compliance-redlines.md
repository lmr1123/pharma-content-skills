# 医药内训 · 合规与素材红线

本 Skill 全流程适用。与具体版式无关。

## 文案

1. **不编造**适应症、用法用量、禁忌、临床数据、市场份额、「第一」「最好」等断言。
2. 主题相关功效/卖点：仅写入业务或药师/合规 **已提供或已标注来源** 的文字；否则槽位 `status: pending_business` 或 `pending_review`。
3. 参考 PPT 上的数字与结论 **默认不当作已审定事实**；迁移到新主题时必须重新确认。
4. 旁白/标题若用于正式培训：以审定原文为准，AI 只负责结构与占位，不负责「写得更好听的药效」。

## 素材

1. **包装、商标、门店实拍、证照**：必须业务授权提供；禁止用生成图冒充实拍包装。
2. **参考课件中的插画/摄影**：默认只学构图与信息层级，**禁止**直接抠图当生产资产（版权与串样风险）。
3. 可用中性示意图、图标、几何装饰作 `system_generate` 占位，并在方案卡标明「占位非终稿」。
4. 人物形象（药师/患者）：注意形象权与刻板印象；无授权不用真实员工肖像。

## 交付表述

1. 对业务说清：本 Skill 产出是 **结构与清单**，不是自动合规通过。
2. 不承诺替代医学/法务审核。
3. 若参考来自竞品或外部机构课件，提醒仅作内部结构学习，注意著作权。

## 与生产仓关系

- 红线在本 Skill 内自洽；生产仓可有更严闸门，两者不互相替代。
- 本 Skill **不**因为「生产仓有金样」就默认复用金样像素。
