# 本课型怎么填 · 疾病+商品场景 PPT（如穿心莲）

- 产物：可编辑 PPTX
- **内容真题样例（对标蓝「急性上呼吸道感染」）：** 同目录 `samples/gold-chuanxinlian.script.json`
- 空白 Word：同目录 `业务提交_空白模板.docx`（若有）
- 填写参考：只学格式；医学结论须业务/药师审定

## 推荐板块（可删可增）

1. 疾病/辨证知识
2. 商品知识
3. 销售场景与话术
4. 其他需要培训的板块（自定）

## 填写要点

- **先读真题样例**再写新主题：页序、字段密度、话术粒度以 `gold-chuanxinlian.script.json` 为准。
- 板块按资料完整度裁剪；没有的整节删除。
- **换题只学结构与写法，不抄穿心莲医学结论**；非金样 theme 写入金样关键词会被引擎硬阻断。
- **不要**再使用已删除的中性假数据样例（示例证候 A / 示例商品 A）。

## 对话示例（复制给 WorkBuddy）

```
我要用【疾病+商品场景 PPT（如穿心莲）】，主题是【病名或商品名】。
请先对照 samples/gold-chuanxinlian.script.json 的真实内容结构整理内容初稿与素材计划，
知识插图用彩色规范 illustration-medical-flat-color-v1（不要全绿插图），再生成成片。
```

## 图片怎么来（重要）

- **业务提供：** 本品包装、权重/对标商品包装（授权真图）
- **WorkBuddy 按《素材计划》生成知识插图：** 默认 `illustration-medical-flat-color-v1`（**彩色多色**）
- **禁止：** 全绿 monochrome 插图；打开穿心莲金样 PPT 改字交付；沿用金样疾病/症状像素
- 内容确认后才会批量生图；绑定本主题新图后才能出片

## 列表 / 模块硬规则

- 有几条写几条；联合用药 2 组 → 成品 2 行
- 禁止空行凑满金样示例数
- 没有的板块整节删除
